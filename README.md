# calculator
## 🧮 About This Project

The **Calculator Web Application** is a simple, modern, and user-friendly calculator developed using HTML5, CSS3, and JavaScript.

This project was created as part of my web development learning journey to strengthen my understanding of JavaScript functions, DOM manipulation, event handling, and interactive user interface development.

The calculator provides a practical way to perform everyday mathematical calculations while demonstrating fundamental front-end development skills.

### 🎯 Project Objectives

- Practice JavaScript fundamentals and functions.
- Understand DOM manipulation and event handling.
- Improve HTML and CSS styling skills.
- Build an interactive and responsive web application.
- Apply problem-solving skills through a practical project.

### 🛠️ Technologies

- **HTML5:** Application structure.
- **CSS3:** Styling and user interface design.
- **JavaScript:** Calculator functionality and logic.
